# Unit 2 Discussion: Stacks and Queues

## Overview

This assignment explores two fundamental linear data structures:

- Stack (LIFO)
- Queue (FIFO)

## Learning Objectives

- Implement stack operations
- Implement queue operations
- Understand LIFO and FIFO behavior
- Create edge cases

## Requirements

## Discussion Board Reflection

Completing this assignment helped me understand how stacks and queues work in Python and how they can be applied to real-world situations. I learned how to implement operations such as push(), pop(), peek(), enqueue(), and dequeue(). I also learned how to test edge cases, including removing an item from an empty structure and checking whether a stack or queue becomes empty after its only item is removed.

One challenge I encountered was understanding the difference between LIFO and FIFO behavior and ensuring that items were removed in the correct order. I overcame this by testing my program with multiple values and reviewing the output. I used a Python list for the stack and a deque for the queue. I also created a Boston Celtics theme to make the assignment more interesting by using game highlights and fans waiting to enter TD Garden.

A stack follows Last In, First Out (LIFO), meaning the newest item is removed first, similar to an undo feature in software. A queue follows First In, First Out (FIFO), meaning the first item added is the first removed, similar to fans waiting in line to enter a Celtics game. This assignment helped me understand why selecting the appropriate data structure is important when developing reliable programs.
